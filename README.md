# zibll-pixiv

`zibll-pixiv` 是一个面向 WordPress + Zibll（子比）主题的 Pixiv 作品图片查看器插件。

插件的目标是让站点访客输入 Pixiv 作品 ID 或作品链接后，在站内预览作品图片，并在需要时保存单张原图。图片由 `pixiv.re` 代理服务提供，浏览器直接请求第三方图片服务，WordPress 服务器不负责图片中转、缓存或长期存储。

> 当前仓库处于开发阶段。本文档描述产品定位、计划能力和运行边界；实际功能以仓库中的插件源码和发布包为准。

## 功能定位

- 支持输入 Pixiv 作品 ID、Pixiv 作品链接和已配置代理域名链接。
- 支持单图预览和多图作品翻页。
- 支持 Zibll 主题灯箱查看大图。
- 支持单张原图下载，不提供批量下载。
- 对无效 ID、作品不存在、代理服务异常、限流和网络超时提供明确提示。
- 支持配置主代理域名、备用代理域名、页面地址和请求超时。
- 支持可选的本地 ID 屏蔽清单；该功能默认关闭，只按作品 ID 或画师 ID 精确匹配。
- 计划支持简体中文、繁体中文、英语、日语和韩语。

## 不提供的能力

- 不提供批量下载、整本下载或按画师批量下载。
- 不把 Pixiv 图片保存到 WordPress 媒体库、服务器磁盘或对象存储。
- 不提供图库聚合、排行榜、推荐流、收藏夹或用户账号体系。
- 不接受任意 `i.pximg.net` 原图链接，也不提供 Cookie/token 注入或访问限制解锁。
- 不接入第三方作品元数据接口、图像识别模型或自动内容审核。
- 不提供年龄确认页、年龄门或 IP 地域限制。

## 运行要求

- WordPress 7.0 或更高版本。
- PHP 8.0 或更高版本；开发目标为 PHP 8.4。
- MySQL 8.0+ 或 MariaDB 10.6+。
- Zibll（子比）主题及其主题灯箱能力。
- 浏览器能够访问配置的 Pixiv 图片代理域名。

默认代理域名为 `pixiv.re`，备用域名为 `pixiv.nl`。代理服务属于第三方服务，稳定性、响应速度和可用性不由本插件保证。

## 安装

发布包准备好后：

1. 在 WordPress 后台进入“插件 → 安装插件 → 上传插件”。
2. 上传 `zibll-pixiv.zip` 并安装。
3. 激活插件。
4. 在插件设置页确认页面地址、代理域名、超时时间和免责声明。
5. 访问插件页面，输入 Pixiv 作品 ID 或链接进行测试。

插件不应写入 Zibll 的 `zibll_options`，设置应保存在插件自己的 option 中。

## 隐私与使用边界

在默认前端直连模式下，用户浏览器会直接向 `pixiv.re` 或 `pixiv.nl` 请求图片，因此用户 IP 地址会对相应第三方服务可见。本站不应在服务器端记录用户查询的作品 ID，也不应保存图片内容。

图片版权归 Pixiv 原作者所有。站点运营方应自行确认所在地区、主机服务商和内容运营政策的适用要求，并在页面中提供免责声明和版权方联系入口。

## 开发状态

当前版本首先完成插件目录、仓库和基础文档建设。后续实现应先完成以下验证，再进入完整功能开发：

1. 验证代理服务的 CORS 和响应头暴露能力。
2. 确定图片预览、错误分级、重试和故障转移的统一请求模型。
3. 确定独立页面的 canonical slug 与 rewrite 规则。
4. 在已授权的 WordPress + Zibll 容器中完成激活、页面、灯箱、下载和卸载验证。
5. 完成 PHP 8.0 语法边界、PHP 8.4 告警、移动端和多语言验收。

详细的阶段、风险、Docker 验证和验收要求见仓库外的项目规划文档。
